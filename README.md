# J.A.R.V.I.S. Multilingual AI

A voice-controlled AI assistant that runs entirely in the browser.
Supports English, French, Spanish, and Haitian Creole.

## Features
- Always-on voice recognition (say "Jarvis")
- Multilingual replies (en / fr / es / ht)
- Text-to-speech output
- No installation, no backend, no API keys
